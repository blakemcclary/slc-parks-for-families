# Raised in SLC · Brand kit v1 (Aug 2026)

Open `style-guide.html` for the full guide. Short version:

**Direction:** Color Field. Flat mid-century colour planes (sometimes tilted 3–6°), flat cut-paper vector illustrations floating on them, one big Fraunces 900 headline, Space Grotesk caps for labels. No crayon/oil-pastel art, no line-art sign, no italics, no drop shadows on print.

**Colour (hex → see palette/ for ASE/GPL/CSS + CMYK starting values):**
Cream #EFE6CE · Paper #F3ECD6 · Mustard #E0A92E · Terra #C44A2E · Blue #3F57C4 · Blue 2 #5E77D6 · Green #2E7D4F · Green Deep #1F5E3A · Pink #E6519B · Brown #43301F · Ink #2B2216

**Type (Google Fonts, SIL OFL):**
- Fraunces, variable — headlines only. wght 900, opsz 144, tracking −25, leading 0.97, sentence case with a full stop, upright only.
- Space Grotesk — labels (700, caps, tracking +220), URLs, body (400).
- Download: Fraunces https://fonts.google.com/download?family=Fraunces · Space Grotesk https://fonts.google.com/download?family=Space%20Grotesk (install the variable TTFs).
- The wordmark inside the logo is artwork, not type. SVG versions (olive / ink / cream, auto-traced and colour-snapped) are in `assets/logo/`.

**Logo:** SVG + PNG in `assets/logo/`. Ink version on cream/paper/mustard; cream version on terra/blue/green/pink. Never the stock olive on mustard (1.7:1 contrast). Min width 1.4 in; 8 in on the yard sign.

**Illustrations:** use the `*-solid.png` files. The site's PNGs are ~80% opacity on purpose and print washed out. Line-art files are for coloring sheets only.

**QR:** `assets/qr/qr-raisedinslc-org-ecH.svg` → https://raisedinslc.org, EC level H. Ink modules on a Paper box, quiet zone ≥ 4 modules. 3 in on the yard sign, 0.9 in on donation stickers, 0.6 in on coloring sheets. Test-scan a proof.

**Templates:** `templates/*.svg`, real size (72 units = 1 in), GUIDES layer: red bleed, pink trim, dashed green safe, dashed blue placement boxes. Delete GUIDES before export.
